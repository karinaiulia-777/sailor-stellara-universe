# Assets

Dieser Ordner ist für eigene Bilder und Ressourcen gedacht.

## Was hier abgelegt werden kann

- Eigene Illustrationen (PNG, SVG)
- Sofias Zeichnungen (als Dateien, bevor sie in die Galerie hochgeladen werden)
- Eigene Icons oder Grafiken

## Hinweis

Die Website verwendet **keine** offiziellen Sailor-Moon-Bilder oder -Grafiken.
Alle visuellen Elemente werden per CSS und Unicode-Zeichen erstellt.

Eigene, selbst erstellte Bilder dürfen hier abgelegt und über die Kunstgalerie hochgeladen werden.
